# BidCheck 商业化产品执行 Plan

> 执行规则：以后所有编码优先服务本 Plan；完成一个 Gate 才进入下一个 Gate。禁止为了“看起来完整”提前扩展无关基础设施。

## 产品定位
面向中国中小企业/个体投标人员的招投标文件智能审查工具。核心价值：降低人工检查漏项、格式/响应偏差和关键条款遗漏的风险，并输出可执行的整改清单。

## 技术路线
- Python 作为核心业务语言
- 保留现有领域层，优先模块化单体
- HTTP 层保持可适配 FastAPI
- SQLite 用于 MVP；达到多租户生产规模后迁移 PostgreSQL
- LLM 通过 Provider 接口接入，不锁定单一模型
- 文件解析、规则引擎、LLM、报告生成均可独立测试

## 严格执行的 6 个阶段

### P1 核心审查闭环
目标：真实 PDF/DOCX/XLSX 输入可以得到结构化审查结果。
- 文件校验与安全限制
- 文本/表格解析
- 招标要求抽取
- 投标响应匹配
- 缺失项/冲突项/高风险项识别
- 风险等级、证据、建议
- 可导出的审查报告
**Gate：核心流程端到端测试通过。**

### P2 AI + 规则双引擎
- 规则优先处理确定性约束
- LLM 处理语义匹配与复杂判断
- Provider 抽象、超时、重试、成本统计
- 结果置信度与证据链
- 防止模型编造原文依据
**Gate：关键结论必须可追溯到输入证据。**

### P3 商业级 Web/API
- FastAPI API adapter
- 登录/租户/权限接入现有基础设施
- 项目、文件、审查任务、报告 API
- 任务状态与错误规范
- 前端最小可售卖工作流
**Gate：新用户可独立完成一次完整审查。**

### P4 收费与成本控制
- 免费额度
- Pro 套餐
- Usage 计量
- 支付 Provider
- 订单幂等
- 超额限制
- LLM 成本监控
**Gate：一次付费后权限和额度正确生效。**

### P5 生产化
- PostgreSQL 迁移路径
- 对象存储适配
- 异步任务队列
- Docker
- 日志、健康检查、错误追踪
- 安全审计、文件隔离、限流
- E2E 回归
**Gate：可部署、可恢复、可观测。**

### P6 商业 MVP
- Landing Page
- 新手引导
- 示例项目
- 产品帮助文档
- 隐私/服务条款占位
- 埋点与核心漏斗
- 上线检查清单
**Gate：陌生用户可注册、试用、完成核心任务并进入付费路径。**
